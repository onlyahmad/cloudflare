INSTALL DOCKER & DOCKER COMPOSE - DEBIAN 13
===============================================

1. Update system
----------------
sudo apt update
sudo apt upgrade -y

2. Install prerequisite packages
---------------------------------
sudo apt install -y ca-certificates curl gnupg

3. Add Docker GPG key
---------------------
sudo install -m 0755 -d /etc/apt/keyrings

sudo curl -fsSL https://download.docker.com/linux/debian/gpg   -o /etc/apt/keyrings/docker.asc

sudo chmod a+r /etc/apt/keyrings/docker.asc

4. Add Docker repository
------------------------
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.asc] https://download.docker.com/linux/debian $(. /etc/os-release && echo "$VERSION_CODENAME") stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null

5. Update repository
--------------------
sudo apt update

6. Install Docker Engine + Docker Compose plugin
-------------------------------------------------
sudo apt install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin

7. Enable and start Docker
--------------------------
sudo systemctl enable --now docker

8. Check Docker service
-----------------------
sudo systemctl status docker

9. Check Docker version
-----------------------
docker --version

10. Check Docker Compose
-----------------------
docker compose version

11. Test Docker
---------------
sudo docker run --rm hello-world

12. Allow current user to run Docker without sudo
-------------------------------------------------
sudo usermod -aG docker $USER

IMPORTANT:
Logout and login again, or run:

newgrp docker

Then test:

docker run --rm hello-world

13. Verify Docker Compose
-------------------------
Create test directory:

mkdir -p ~/docker-test
cd ~/docker-test

Create compose file:

nano compose.yml

Example content:

services:
  nginx:
    image: nginx:alpine
    container_name: test-nginx
    ports:
      - "8080:80"
    restart: unless-stopped

Start:

docker compose up -d

Check:

docker compose ps

Access:

http://IP-SERVER:8080

Stop and remove:

docker compose down

14. Useful Docker commands
--------------------------
List containers:

docker ps

List all containers:

docker ps -a

List images:

docker images

List volumes:

docker volume ls

List networks:

docker network ls

View logs:

docker logs -f CONTAINER_NAME

Restart container:

docker restart CONTAINER_NAME

Stop container:

docker stop CONTAINER_NAME

Remove container:

docker rm CONTAINER_NAME

Pull image:

docker pull IMAGE_NAME

15. Useful Docker Compose commands
----------------------------------
Start:

docker compose up -d

Stop:

docker compose down

Restart:

docker compose restart

View logs:

docker compose logs -f

View status:

docker compose ps

Pull latest images:

docker compose pull

Recreate containers:

docker compose up -d --force-recreate

16. Troubleshooting
-------------------
Check Docker:

systemctl status docker

Check Docker logs:

sudo journalctl -u docker -n 100 --no-pager

Check Docker socket:

ls -l /var/run/docker.sock

Check Docker information:

docker info

If permission denied:

sudo usermod -aG docker $USER

Then logout/login or:

newgrp docker

17. Uninstall Docker (if needed)
--------------------------------
sudo apt remove -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin

Optional: remove Docker data:

sudo rm -rf /var/lib/docker
sudo rm -rf /var/lib/containerd

WARNING:
Removing /var/lib/docker deletes Docker containers, images,
volumes, and other Docker data stored there.

NOTE FOR DEBIAN 13
------------------
Docker Compose is installed as the Docker CLI plugin.

Use:

docker compose version

NOT:

docker-compose version

The recommended command is:

docker compose up -d
